# OSA domain-list source review

Last reviewed: 10 September 2026

## Result

No public source found in this review is a stronger replacement for OSA Tracker plus Blocked.org.uk's OSA page. The project therefore keeps both as complementary live OSA sources.

## Sources assessed

| Source | Assessment |
| --- | --- |
| [OSA Tracker](https://osatracker.co.uk/) | Best dedicated, exportable OSA domain list found. Community-maintained, moderated, categorized, includes explicit entries when requested, and offers domain-only exports. |
| [Blocked.org.uk OSA page](https://www.blocked.org.uk/osa-blocks) | Useful complementary transparency source with evidence links and entries absent from OSA Tracker. It also contains shutdowns, relaunches and occasional non-OSA geoblocking, so provenance is retained. |
| [the-Jamz/dns-censored](https://github.com/the-Jamz/dns-censored) | Purpose-built for VPN routing, but archived on 12 November 2025. Its maintainer directs users to OSA Tracker. Its published list had four domains when archived. |
| [Chimestrike/starmer-stoppy](https://github.com/Chimestrike/starmer-stoppy) | Independent repository described as an OSA list, but contains only `imgur.com`, already covered by both live sources. |
| [Ofcom FOI response, 17 November 2025](https://www.ofcom.org.uk/siteassets/resources/documents/about-ofcom/foi/2025/november/websites-andor-online-services---shut-down-or--geoblock.pdf?v=407965) | Ofcom explicitly said it did not hold a list of websites or services that shut down or geoblocked the UK because of the OSA. It named Krakenfiles, Nippydrive, Nippyshare and Nippyspace as examples; these can be checked against the live sources, but the response is not a maintained export. |
| [SitesBlocked UK](https://sitesblocked.com/country/united-kingdom) | Lists 59 mixed UK restrictions, mostly copyright, adult and other categories. It is not OSA-specific and offers no router-ready OSA export found in this review. |
| [OONI](https://explorer.ooni.org/) | High-quality open censorship measurements, but observations are network-specific and do not establish that an outage or interference was caused by the OSA. It is unsuitable for automatic inclusion without a separate attribution and review process. |
| OSA enforcement trackers | Track regulatory actions and documents rather than domains that users should route through a VPN. Useful as evidence, not as a replacement domain feed. |

## Recheck criteria

A replacement or additional source should provide a maintained machine-readable domain export, explain its inclusion rules, distinguish OSA restrictions from unrelated geoblocking, include update dates or evidence, and permit reuse. Candidate entries should retain source provenance rather than silently entering the combined feed.

Search-engine and public GitHub searches were used during this review. Absence from search results cannot prove that no private, unindexed or newly created list exists.
